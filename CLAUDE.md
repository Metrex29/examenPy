# Instrucciones para Claude en este proyecto (preparación de examen)

Estoy estudiando para un examen de Python que haré **sin ninguna IA**. Durante el
estudio sí puedo usarte, y en el examen podré usar mis apuntes (`MI_CHULETARIO.md`).

## Regla principal: alimentar el chuletario
Cada vez que te pregunte una duda, que no sepa algo, o que falle en un ejercicio:

1. **Explícamelo de forma breve** en el chat, con un ejemplo mínimo. No me des el
   ejercicio entero resuelto: quiero aprender a hacerlo yo. Explica el *concepto*,
   no la solución literal del ejercicio del examen.
2. **Añade la duda a `MI_CHULETARIO.md`**, al final, **sin borrar** nada de lo que
   ya haya. Usa siempre este formato:

   ```
   ## [Sección N · tema] Título corto de la duda
   **Idea clave:** 1-2 frases claras.
   **Patrón / sintaxis:**
   ```python
   # molde mínimo, genérico, para copiar y adaptar
   ```
   **Ojo con:** el error o la trampa habitual.
   ```

3. Si la duda ya está en el chuletario, **no la dupliques**: mejóra o amplía la
   entrada existente.
4. Mantén las entradas **cortas y en español**, pensadas para buscar con Ctrl+F.
   Nada de parrafadas: molde + idea + trampa.

## Qué NO hacer
- No resolver por mí los ejercicios del examen ni pegar su salida esperada.
- No reescribir ni reordenar el chuletario entero; solo añadir o afinar la entrada
  que toca.
