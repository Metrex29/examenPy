# 📝 Exámenes de práctica

Dos exámenes nuevos al estilo del modelo, **una pregunta por sección** (10 cada uno).
Hechos para repasar antes del examen real.

| Archivo | Para qué |
|---|---|
| `Examen_A.ipynb` | Examen A para hacer (celdas vacías + salida esperada) |
| `Examen_B.ipynb` | Examen B para hacer |
| `Examen_A_SOLUCIONES.ipynb` | Soluciones del A (abrir **después** de intentarlo) |
| `Examen_B_SOLUCIONES.ipynb` | Soluciones del B |
| `Examen_C.ipynb` | **Examen C (nivel alto)**: MRO, reduce avanzado, recursión anidada |
| `Examen_C_SOLUCIONES.ipynb` | Soluciones del C |

## Cómo usarlos
1. Abre `Examen_A.ipynb`. Resuelve cada pregunta en su celda vacía.
2. En las secciones 2–9 compara tu resultado con la **"Salida esperada"**.
3. En las secciones 1 y 10 (lectura/teoría) escribe tu predicción y luego mira las soluciones.
4. Solo cuando lo hayas intentado, abre el `_SOLUCIONES` para corregir.

> Son preguntas **distintas** a las del modelo, pero del mismo tipo y dificultad.
> Si clavas estos dos, llevas el examen muy trabajado.
